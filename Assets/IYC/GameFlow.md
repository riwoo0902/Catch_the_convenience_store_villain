# 편의점 근무 루프

`Assets/Lrw/Scene/Lrw_Scene.unity`를 열고 Play → 시작 버튼으로 실행한다. 빌드의 첫 씬도 이 타이틀이다. 편의점 씬을 직접 Play해도 도입부터 실행한다.

## 진행

- 검은 화면의 도입 스토리 → 20:00 근무 시작과 체험형 튜토리얼 → 일반 근무 → 24:00 퇴근 연출 → 엔딩 → 결과.
- 현실 600초가 게임 속 4시간이다. 휴대폰과 유튜브 사용 중에도 시간이 흐른다. 스토리·사망·퇴근부터는 게임 시간이 정지한다.
- 첫 스토리 문장은 제공된 고용 신청서 이미지로 대체한다. A4 용지 비율(210:297)로 표시하며, 클릭 한 번으로 기존 두 번째 문장부터 이어진다. 이후 문장 출력 중 클릭은 현재 문장 완성, 다음 클릭은 다음 문장이다. 신청서의 인쇄 문구는 원본 그대로다.
- TAB으로 휴대폰을 열고 시계 앱에서 현재 시각과 퇴근까지 남은 시간을 확인한다.
- 체험 안내는 사장님이 알려 주는 말투로 표시하며, 화자 이름은 "사장님"으로 고정한다. 체험은 행동 하나씩 진행한다. TAB으로 열기 → 시계 앱 클릭 → 설명 확인 → 뒤로 클릭처럼 각 조작을 분리한다. 주식(체력), 유튜브, 메일도 같은 흐름이다. 설명은 확인 버튼 또는 Enter를 눌러야 넘어가며 시간 경과로 자동 진행하지 않는다.
- 눌러야 할 앱·뒤로·키패드·통화 버튼에 노란 테두리를 표시하고, 안내 글자를 그 버튼 높이에 맞춰 배치한다. 다른 조작을 막지 않으며, 잘못된 앱을 열거나 휴대폰을 닫으면 해당 단계로 돌아오는 안내를 표시한다. 전화번호를 잘못 누르면 CLR로 초기화하도록 안내한다.
- 앱을 확인한 뒤 휴대폰 닫기 → 단일 빌런 등장 → 휴대폰 열기 → 전화 앱 → 첫 1 → 둘째 1 → 2 → 통화를 각각 별도 단계로 안내한다. 경찰 처리 후에도 확인/Enter를 눌러 교육을 마친다.
- 튜토리얼도 실제 근무다. 시간과 체력이 정상적으로 변하고 사망·24시 종료도 적용된다. 안내는 패널 없이 글자만 띄우며, 눌러야 할 버튼이 있으면 휴대폰 바깥 옆쪽 같은 높이로 따라붙는다. 클릭이나 이동을 가로막지 않는다.
- 전화 단계에서 입구에 벽돌 빌런 한 명만 등장한다. 직접 112를 눌러 신고하고 기존 경찰 처리/퇴장까지 끝나면 튜토리얼이 완료된다. 완료해도 시각·체력·상품 상태를 초기화하지 않는다.
- 튜토리얼 중에는 일반 빌런 타이머를 멈춘다. 튜토리얼 완료 또는 재시작 뒤 첫 일반 빌런과 이후 등장 간격은 20~40초다. 동시 등장 수와 빌런 자체 행동은 기존 스포너/빌런 구현을 따른다.
- 전화 앱에서 `1 → 1 → 2 → 통화`. 누른 순간 신고 내용이 결정되고 5초 뒤 경찰이 출동한다. 출동 및 방문 중에는 다시 신고할 수 없다.
- 신고 순간 빌런이 없었으면 허위 신고다. 경찰이 플레이어에게 다가와 빌런 제압과 같은 내려치기 모션을 재생한다. 타격 시점에 체력 20을 한 번 깎고 출입구로 돌아간다. 신고 뒤 새 빌런이 나타나도 판정은 바뀌지 않는다.
- 체포 사이에도 체력과 어질러진 물건이 유지된다. 기존 E 정리·유튜브 회복을 사용한다.
- 근무 중에는 점장이 메일로 추가 업무를 계속 보낸다. 튜토리얼이 끝나고 15초 뒤 첫 업무가 오고, 이후 45~75초마다 새 업무가 도착하며 동시에 최대 3건까지 열린다.
- 업무 종류는 상품 정리 N개, 112 신고 N건, 매장 N초 지키기다. 목표를 채우면 즉시 체력을 보상으로 돌려준다(업무당 8~15). 완료 카드는 15초 뒤 목록에서 사라진다.
- 새 업무 도착과 완료는 화면 상단 알림으로 알려 주고, 메일 앱에는 "점장님 추가 업무"가 최신순으로 위에 쌓인다. `Assets/Resources/Quests`의 기존 퀘스트는 그 아래 "기본 업무"로 계속 표시한다.
- 체력 보상은 최대 체력을 넘지 않으며, 튜토리얼 중과 근무 종료 뒤에는 업무가 오지 않는다.
- 사망하면 사망 스토리 → 재시작/나가기. 나가기는 프로그램 종료다. 재시작은 도입과 체험형 튜토리얼을 모두 건너뛰고 시각·체력·물건을 초기화한다. 타이틀에서 새로 시작하면 둘 다 다시 진행한다.
- 24:00에는 살아 있는 빌런이나 진행 중인 신고와 무관하게 퇴근한다. 결과의 체포 수는 경찰의 실제 제압 성공만 센다.
- 플레이어가 Y=-10 아래로 떨어지면 떨어진 위치의 X/Z를 그대로 유지하고 Y만 시작 높이 또는 2 이상으로 올린다. 낙하 속도는 초기화한다. 기존 Alt 복구와 복구 트리거도 X/Z를 유지한다.

## 조정할 곳

`Assets/IYC/Resources/GameFlowSettings.asset`에서 근무 시간, 글자 출력 속도, 퇴근 연출 길이, 시작/사망/엔딩 문구를 설정한다. 기본 문구는 감정노동·고객 갑질과 노동자 보호를 주제로 쓰여 있다. 첫 페이지 이미지는 같은 에셋의 Opening Application에서 교체한다. 기본 문구는 `GameFlowSettings.cs`에 있고, 설정 에셋의 Inspector에서 덮어쓸 수 있다. 시계 아이콘은 원본 `clock-512x512_97226.png`를 참조하며 런타임 Sprite로 표시한다.

추가 업무의 종류·목표 수치·체력 보상은 `Assets/IYC/01.Scripts/Quests/ShiftQuestBoard.cs`의 `Templates` 배열에서 조정한다. 도착 간격과 동시 진행 수도 같은 파일 상단 상수다.

`ConvenienceStoreVillainSpawner`의 Arrival 필드에서 20~40초를 조정한다. 빌런/경찰의 프리팹과 행동 설정은 기존 `VillainSpawnSettings`를 사용한다.

퇴근 연출은 기존 편의점 출입문을 배경으로 단순한 알바 캐릭터가 걸어 나가는 장면이다. 씬에 `ShiftExitInside`, `ShiftExitOutside`라는 Transform을 둘 다 추가하면 해당 위치를 출발/도착 지점으로 사용한다. 없으면 출입문과 진열대 위치에서 자동으로 방향을 계산한다.

## 다른 작업과 연결

코드는 `Assets/IYC/01.Scripts/GameFlow/`에 있다. `GameLoopController`는 편의점 씬마다 자동 설치되므로 씬에 별도 수동 추가할 필요가 없다.

- `GameLoopController.AllowsGameplay`: 현재 근무 중인지 확인한다. 게임 루프가 없는 빌런 전용 테스트 씬에서는 true다.
- `GameLoopController.TutorialActive`: 체험형 튜토리얼 진행 중인지 확인한다. `AllowsRandomSpawns`는 튜토리얼이 끝나야 true다.
- `ShiftTutorial`은 앱 사용 및 신고 처리 상태를 관찰한다. `PlayerHUDController.CurrentApp`은 휴대폰이 닫혀 있으면 `None`이다.
- `GameLoopController.Instance.RecordArrest()`: 새 체포 연출이 실제 제압을 완료했을 때 한 번 호출한다. 현재 경찰 연결에서 이미 호출한다.
- `PoliceResponseController.TryBeginEmergencyCall()`: 신고 순간 판정/중복 제한. 반환값 true일 때만 카운트한다.
- `CompleteEmergencyCall()`: HUD의 5초 타이머가 끝나면 경찰 출동.
- `CancelEmergencyCall()`: 사망/24:00/씬 전환 시 예약과 현장 경찰을 정리한다.

기존 Lrw는 시작 버튼 연결만 수정했고, 빌드 씬 목록에 타이틀과 편의점을 추가했다. 기존 SampleScene 항목도 유지한다.

검증 실행 방법과 검증 범위는 `GameFlowValidation.md` 참고.
