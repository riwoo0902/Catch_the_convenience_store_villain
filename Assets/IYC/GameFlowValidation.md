# 게임 루프 검증

Unity Edit 모드에서 `Tools > Game Flow > Validate Loop`를 실행한다. 저장하지 않은 씬이 있으면 먼저 저장한다. 이 검증은 Lrw 타이틀을 열고 실제 시작 버튼, 게임 진행 UI, 전화 키패드, 결과 버튼을 호출한다. 실행이 끝나면 원래 활성 씬으로 돌아간다.

명령줄에서는 아래처럼 실행한다. `-quit`을 추가하지 않는다. 검증기가 Play 모드를 종료한 뒤 성공은 0, 실패는 1로 Unity를 종료한다. 이미 같은 프로젝트가 열려 있으면 메뉴를 사용한다.

```powershell
& 'C:/Program Files/Unity/Hub/Editor/6000.3.10f1-x86_64/Editor/Unity.exe' `
  -batchmode `
  -projectPath 'C:/TeamProject/Catch_the_convenience_store_villain' `
  -executeMethod CWH.GameFlow.Editor.GameFlowValidation.RunBatch `
  -logFile 'Logs/GameFlowValidation-unity.log'
```

`Logs/GameFlowValidation/<실행시각>/`에 `report.json`, `report.txt`, 화면 PNG를 남긴다. 화면 검토가 필요한 실행에서는 `-nographics`를 사용하지 않는다. 그래픽 환경에 따라 화면 PNG가 생성되지 않을 수 있으며, 이 경우 보고서에 따로 기록된다. 보고서의 상태 검증 성공은 화면을 사람이 확인했다는 뜻이 아니다.

검증 범위:

- 실제 타이틀 시작 버튼 → 도입 스토리 → 근무 시작. 스토리 중 시간 정지, 클릭으로 현재 문장 완성과 다음 문장 진행.
- 20:00 시작, 기본 현실 600초, 시계 앱 버튼 및 시간 표시, 휴대폰을 열어도 시간과 이동 유지.
- 첫 페이지의 신청서 이미지 표시와 한 번 클릭 후 기존 두 번째 문장 복원.
- 스토리 직후 단일 행동 안내, 앱·뒤로 버튼의 강조, 잘못된 앱/숨겨진 앱/잘못된 뒤로 버튼으로 단계 진행 불가, 시계·주식·유튜브·메일의 명시적 확인. 대기만으로는 자동 진행하지 않으며 근무 시간은 계속 흐른다.
- 전화번호를 잘못 누른 경우 CLR 강조와 재입력, 첫 1·둘째 1·2·통화의 개별 단계, 완료 안내 역시 확인 전에는 종료하지 않음.
- 전화 단계의 단일 빌런 생성, 실제 112 신고·5초 출동 후 처리 완료, 튜토리얼 종료 시 시간 유지와 일반 빌런 재개.
- 잘못된 번호 거부, `1 → 1 → 2 → 통화`, 즉시 접수 및 중복 방지, 5초 이전 경찰 미등장.
- 빌런 없는 신고 판정, 경찰 도착 후 체력 20 감소, 피격 무적 중에도 페널티 적용, 같은 신고로 중복 피해 없음.
- 허위 신고는 빌런 제압과 같은 공격 모션을 사용하며, 공격 시작 시 즉시 피해를 주지 않고 타격 시점에 적용.
- 플레이어가 바닥 아래로 떨어지면 X/Z를 유지하며 Y만 복구하고 수직 낙하 속도를 초기화.
- 사망 스토리 → 게임 오버 결과 → 재시작. 재시작 시 도입과 튜토리얼 생략, 20:00 및 최대 체력 복원.
- 23:59에는 근무 유지, 24:00에는 즉시 근무 종료 및 퇴근 연출, 엔딩, 결과, 타이틀 복귀.
- 튜토리얼 도중 사망해도 게임 오버로 전환되고 재시작하면 미완료 튜토리얼을 생략한다. 새 게임은 튜토리얼을 다시 시작하며, 튜토리얼 도중 24시가 되어도 퇴근으로 전환한다.

유튜브 앱 단계는 초기화하지 않은 WebView를 검증용으로 주입해 실제 앱 버튼과 확인 버튼으로 진행하는 과정을 확인한다. 네트워크 접속과 영상 재생 성공 여부를 검증한 것은 아니다.

허위 신고를 독립적으로 검증하기 위해 해당 구간에서만 런타임 빌런 생성 코루틴과 지속 체력 효과를 멈춘다. 경찰 경로 탐색 자체는 담당 구현에서 검증할 수 있도록 경찰을 플레이어 곁으로 옮겨 도착 처리와 페널티를 확인한다. 24시 경계는 메모리의 경과 시간만 앞당긴다. 프로젝트의 씬·설정 에셋은 변경하지 않는다. 키보드/마우스 물리 입력, 실제 YouTube 재생 및 네트워크, 외부 담당 빌런의 공격·체포 연출은 이 자동 검증의 범위가 아니다.
